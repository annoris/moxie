# Contributing to MOXIE &amp; Unlocking Full Source Code

Thank you for your interest in **MOXIE** (`https://github.com/annoris/moxie`)!

This public repository lets everyone **explore the live demo ([`annoris.github.io/moxie`](https://annoris.github.io/moxie/)), study the architecture, and inspect the campaign visuals in [`./moxie/`](./moxie/)**.

The **complete downloadable source code** (Next.js 15 + React 19 + GSAP Inertia + Lenis + custom SVG transition scribble &amp; cursor physics) is **not publicly distributed** — it is unlocked exclusively for **approved contributors** through our *Contribute-to-Unlock* program.

---

## 🔑 How to Unlock Full Source Code Access

Star [`annoris/moxie`](https://github.com/annoris/moxie) and complete **any one** of the following paths:

### Option 1 — Valuable Pull Request on `annoris/moxie`
Submit a PR to [`https://github.com/annoris/moxie`](https://github.com/annoris/moxie) that strengthens the community showcase:
- Deep-dive documentation, diagrams, or motion breakdowns in `ARCHITECTURE.md` or `README.md`.
- Guides on GSAP `InertiaPlugin`, `quickTo` elastic cursors, or Lenis scroll optimization.
- Complete, high-quality translations of the documentation.

### Option 2 — High-Signal Technical / UX Audit Issue
Open a structured Issue on [`https://github.com/annoris/moxie/issues`](https://github.com/annoris/moxie/issues) covering:
- Performance, accessibility (`prefers-reduced-motion`, keyboard navigation), or responsive layout audits of the live demo.
- Creative motion or campaign interaction concepts tailored to MOXIE's aesthetic.

### Option 3 — Direct Collaboration or Sponsorship
Want to collaborate or sponsor MOXIE's creative engineering work? Reach out with your GitHub handle:
- **Email:** `hello@moxie.agency`
- **Subject:** `[MOXIE Source Access] Collaboration — @your-handle`

---

## 📋 Pull Request Steps

1. **Fork** [`annoris/moxie`](https://github.com/annoris/moxie).
2. **Create a branch**:
   ```bash
   git checkout -b docs/gsap-inertia-breakdown
   ```
3. **Commit clean Markdown / documentation improvements**.
4. **Open a Pull Request** on `annoris/moxie` clearly explaining the value of your contribution.
5. **Review &amp; Unlock**: Once your PR is merged or approved, you will receive private access instructions directly via your GitHub account.
